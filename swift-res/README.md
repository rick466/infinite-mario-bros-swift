# Swift Playgrounds port

This directory is the first native iPad port of the original Java Infinite Mario Bros project.

Target:
- Swift Playgrounds on iPad
- SpriteKit renderer
- 320x240 logical game resolution
- touch controls
- later hardware-keyboard controls
- original res assets reused as bundled resources

The original Java engine remains untouched outside this directory.

Next port stages:
1. Resource loader and sprite-sheet slicing
2. Level data loader
3. Mario physics and collision
4. Level generation
5. Enemies and items
6. Title, map, level, win and lose scenes
7. Sound and MIDI replacement
