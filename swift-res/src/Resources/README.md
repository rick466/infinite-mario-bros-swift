# Original resources

Copy the contents of the repository's original res directory into this folder.

Required first:
- mariosheet.png
- mapsheet.png
- bgsheet.png

Then add:
- smallmariosheet.png
- firemariosheet.png
- enemysheet.png
- itemsheet.png
- particlesheet.png
- font.gif
- logo.gif
- title.gif
- endscene.gif
- gameovergost.gif
- worldmap.png
- tiles.dat
- test.lvl
- mus/
- snd/

The Java source expects these resources at the root of its classpath. The Swift port will instead access them through the Swift Playgrounds app bundle.
